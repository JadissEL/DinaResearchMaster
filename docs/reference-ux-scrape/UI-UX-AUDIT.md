## Cross-site synthesis for DinaResearch

### Navigation
- **Volume10 / Apple:** Minimal top nav, brand left, sparse links
- **New Yorker:** Rich taxonomy nav + section labels on homepage
- **Wealthsimple:** Product modules as nav destinations
- **Fridays:** Utility nav (book, find us) + promo-first home

### Hero patterns
- **Volume10:** Statement headline + case study cards immediately below
- **Apple:** Full-bleed product tiles, one hero per scroll viewport
- **New Yorker:** Featured story + Today's Mix grid
- **Wealthsimple:** Motion/video hero + product grid
- **Fridays:** Rotating promo carousel + membership CTA

### Recommended DinaResearch mapping
| Pattern | Source | Apply to |
|---------|--------|----------|
| Split headline + case study rail | Volume10 | Home hero + Featured Research |
| Scroll-section product blocks | Apple / Wealthsimple | Intelligence categories |
| Today's Mix editorial grid | New Yorker | Home curated feed |
| Trust / social proof strip | Wealthsimple | About / footer |
| Event/promo energy | Fridays | Active discussions module |
