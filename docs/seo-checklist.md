# SEO Checklist

## Per article (automated in publish script)

- [ ] Unique title and meta description (50–160 chars)
- [ ] AI summary (150+ words neutral)
- [ ] Canonical URL via metadata
- [ ] Open Graph + Twitter cards
- [ ] JSON-LD Article schema
- [ ] BreadcrumbList schema
- [ ] Key takeaways block
- [ ] Topic cluster assignment
- [ ] Entity associations
- [ ] Internal links (3+ recommended)

## Site-wide

- [x] `/sitemap.xml`
- [x] `/feed.xml` (RSS)
- [x] `/llms.txt`
- [x] `/robots.txt`
- [x] Semantic HTML landmarks
- [x] Person schema on About

## AI discoverability

- Structured blocks (not HTML blobs)
- Citation-friendly reference lists
- Entity hub pages (`/companies/[slug]`)
- Topic pillar pages (`/topics/[slug]`)
